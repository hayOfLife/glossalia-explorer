# Таблица знаков для транскрипции для печати

| Знак | Когда ставим | Пример |
| --- | --- | --- |
| * | Пауза внутри слова, обособленный звук | а*равви, наоши*дерект |
| + | Соединение частей одного слова (вместо "-") | наем+едро, Едро+шеон, Е+дурва |
| = | Дальше — объяснение/раскрытие предыдущего слова | Елохим = Творец, руах = дух |
| - | Связь между словами (пауза-связь сильнее запятой) | Елохим - а-равви |
| ! | Граница единицы молитвы: прошение, имя, повеление. Не крик — блок. | Елохим!, Е!, Ешем! |
| ? | Открытый вопрос без ответа | В наказание нам или погибель? |
| , | Перечисление без границы блока (вес меньше "!") | Наставь, исправь, свяжи |
| . | Нейтральное завершение; в молитве почти не используется |  |
| (...) | Пометка автора, например при неопределённым звуком который между тем что за скобкой и в скобке | Е(э)рогорн |
| ((...)) | Двойные скобки — личный голос автора рядом с голосом духа | равви((блабла)) |
| БОЛЬШАЯ БУКВА | Ударение внутри слова (не первая буква) | дЕрект, аЯдре |
| / | Просто конец мысли / разделение смыслов | наши+дерек / спаси |
| [↑] | Вопрос, удивление, напряжение | кто&#91;↑&#93;(→)я |
| [↓] | Утверждение, завершение, спокойствие | я[↓] |
| [>] | Выделение важного слога в слове | м[>]а[•]р[•]а |
| [+] | Позитивная эмоция | слово[+] |
| [-] | Негативная/грустная эмоция | слово[-] |
| [@] | Страх, благоговение | слово[@] |
