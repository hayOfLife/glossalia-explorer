# Сайт «Глоссалия»

Сайт показывает выбранные материалы [Glossolalia Explorer](https://github.com/kva4991/glossolalia-explorer). Посетители читают статические файлы; сервер не выполняет запрос к БД при каждом открытии страницы. После настройки MySQL записи будут храниться в БД, а оператор сможет обновлять опубликованный JSON-снимок консольным скриптом.

## Состояние первой версии

- Разделы: «О глоссалии», «Новости», «Сегодня», «Каталог ситуаций», «Донат».
- В «Сегодня» текущий день выбирается по московскому времени. Можно переключать месяцы и выбирать любую дату.
- Подготовлены шесть карточек с подтверждённой ручной транскрипцией: `§T00014`, `§T00016`–`§T00020`. Показан исходный текст без автоматического вывода языка или перевода.
- У карточек указана **дата получения транскрипции**. Она не считается датой аудиозаписи; точное время для этих карточек неизвестно.
- Новости, каталог ситуаций и ссылка для доната пока не наполнены.
- Входа пользователей и публичных форм нет.

## Структура

- `public_html/` — единственный каталог, который должен быть доступен посетителям.
- `public_html/data/entries.json` — опубликованный снимок записей для браузера.
- `database/schema.sql` — схема MySQL 5.7.
- `database/seed.json` — начальные шесть записей, извлечённые из публичных карточек репозитория.
- `database/config.example.php` — образец параметров БД без учётных данных.
- `scripts/import.php` — однократный импорт начальных записей в пустую таблицу.
- `scripts/publish.php` — создание нового снимка из опубликованных записей БД.

## Локальный просмотр

Запустите веб-сервер с корнем в `public_html/`, например `python -m http.server 8765 --directory public_html`, и откройте `http://127.0.0.1:8765/`. Прямое открытие `index.html` как файла не подходит: браузер может запретить чтение JSON.

## Подготовка БД и размещения

Эти действия пока **не выполнялись**. Для работающего сайта с БД потребуются следующие шаги:

1. Разместить содержимое `public_html/` в публичной папке `public_html` на SpaceWeb и включить HTTPS. `database/` и `scripts/` должны находиться на уровень выше публичной папки.
2. Создать базу MySQL и выполнить `database/schema.sql` один раз.
3. Создать `database/config.php` по образцу `config.example.php` вне публичного каталога и заполнить параметры БД. Файл исключён из Git.
4. Выбрать PHP 8.1 или новее и включить `short_open_tag` для консольных скриптов. Команды: `php -d short_open_tag=1 scripts/import.php`, затем `php -d short_open_tag=1 scripts/publish.php`.
5. После каждого изменения опубликованных записей в БД повторно запускать `scripts/publish.php`. На странице появится новый JSON-снимок.

Календарная дата хранится в БД как Unix timestamp в UTC для полуночи соответствующего дня по Москве. Такой timestamp служит ключом календарного дня и не обозначает время создания аудио.

Бесплатный тариф SpaceWeb ограничивает процессорное время MySQL. Статический снимок снимает нагрузку чтения с БД, но доступность для 100 одновременных посетителей можно подтвердить только проверкой размещённого сайта.
