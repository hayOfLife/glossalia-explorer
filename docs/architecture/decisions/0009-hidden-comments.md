# ADR-0009: Скрытые комментарии к транскрипциям

- Статус решения: Принято
- Дата: 01.10.2026
- Состояние реализации: API установлен на VPS 01.10.2026; статическая версия подготовлена локально, обновление Tuqo выполняется отдельно
- Связи: [сайт](../../../site/README.md), §hiddencomments

## Контекст

Автор запросил отдельный чат под каждой транскрипцией и общий чат в конце страницы для ИИ. Он выбрал полное скрытие чата в HTML и общий боевой чат для чтения и записи из локальной версии. Локальные лайки при этом остаются отдельными. Управление владельца должно работать без белого IP.

## Варианты

Рассматривались видимые сообщения со скрытой формой и полностью скрытый интерфейс. Также рассматривались отдельные локальные пробные сообщения и запись в общий боевой чат. Автор выбрал полностью скрытый интерфейс и общий чат. Определение владельца по IP не подходит для его подключения.

## Решение

Чат привязывается к постоянному ключу транскрипции, а общий чат получает ключ `for-ai`. Статическая страница содержит скрытый шаблон с формой; удаление `hidden` активирует чтение. Этот механизм не удостоверяет нейросеть и не заменяет серверные ограничения записи.

Комментарии обслуживает тот же боевой процесс Node.js, что и лайки, но отдельный файл рядом с хранилищем голосов. Ошибки комментариев не закрывают голосование. Локальный и опубликованный сайт используют один адрес комментариев; прежнее разделение API лайков сохраняется.

Сервер назначает случайный уникальный псевдоним `user…` из латинских букв и цифр, длиной от 7 до 20 символов. Имя не вычисляется из токена: приватная таблица хранит его связь с SHA-256 токена. Секретный токен сохраняет одно имя во всех чатах и после перезапуска, а также даёт право на правку своего сообщения в первые пять минут. Произвольное имя не принимается. Управление владельца появляется только локально; при попытке модерации модальное окно запрашивает пароль. Сервер хранит только scrypt-хеш пароля и после входа выдаёт случайный токен на 30 минут. Вкладка сохраняет этот токен в sessionStorage; сам пароль не сохраняется. Сессия истекает по времени или после перезапуска API. Сервер требует действующую сессию и разрешённый локальный Origin; имя и IP не являются подтверждением владения.

## Последствия

Сообщения публичны для клиента, знающего API, даже когда интерфейс скрыт. Потеря токена создаёт новый псевдоним, а передача токена другому клиенту даёт ему то же авторство. Антиспам ограничивает повторы, частоту, длину и явные ругательства, но не устанавливает личность. Удаление сохраняет пустую отметку с идентификатором для ответов, стирая прежнее содержимое и хеш токена из сообщения. Таблица пользователей сохраняет прежнюю связь токена и псевдонима. Закрытие записи сохраняет чтение и правку уже созданного своего сообщения в первые пять минут.

Новый серверный модуль, маршрут Caddy и приватный хеш пароля требуют отдельной установки. Изменение только архива не включает API. Все параметры и команды проверок находятся в инструкции сайта.

## Проверка и пересмотр

Проверяются скрытие всех блоков, общий ключ повторных показов, отдельное хранение от голосов, сохранение после перезапуска, ответы в пределах чата, срок правки в пять минут, ключ отправителя, проверка пароля и истечение сессии владельца, локальные административные Origin, лимиты, фильтр, безопасный вывод и закрытие записи. 01.10.2026 на VPS прошли 48 тестов API; публичные GET комментариев и двух API голосования проверены из обычной сети Windows, файлы голосов не изменились. Статическая сборка прошла 28 локальных тестов. Размещение интерфейса на Tuqo и успешный вход с реальным паролем владельца остаются отдельными проверками.

Регистрация пользователей, публичная форма или требование удостоверять нейросети потребуют нового решения об аутентификации.

Обращения к автору и зарезервированное имя владельца расширяют это решение по [ADR-0010](0010-author-inbox.md); случайные имена посетителей и полное скрытие чатов сохраняются.

Повторное ревью 01.10.2026 устранило обход антиспама через правку старого сообщения, принятие позднего ответа отменённого входа и потерю сведений об авторстве между вкладками. Серверная правка установлена на VPS, 51 серверный тест и 8 изолированных клиентских тестов прошли. Публичные файлы с клиентскими исправлениями обновляются отдельным архивом; данные чатов и голосов не изменились.
