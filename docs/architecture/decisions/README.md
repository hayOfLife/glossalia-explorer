## Порядок работы

Новый ADR создаётся по [шаблону](template.md) со следующим свободным номером. Допустимые статусы: «Предложено», «Принято», «Отклонено» и «Заменено ADR-NNNN».

Новое решение, меняющее принятое, получает новый номер; старый документ сохраняет контекст и ссылку на замену. Исправление опечатки не требует нового ADR. Одновременно обновляются индекс, реестр, тематические документы и проверки из [матрицы](../../CHANGE_IMPACT.md).

Не оформляйте неизвестный выбор как принятое решение. Например, место Android-распознавания остаётся открытым.
