# Гипотеза о смысле жизни человека с точки зрения Бога

## Формулировка автора

> На самом деле всё просто: по делам их узнаете их — Бог хочет узнать, что, кем является конкретный человек.

## Статус

Это авторская гипотеза о Божьем намерении, а не установленное богословское утверждение. Фраза «по делам их узнаете их» сохранена как формулировка автора без привязки к конкретному библейскому стиху.
