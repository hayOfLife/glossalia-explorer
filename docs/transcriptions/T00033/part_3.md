# Практическая инструкция: «Интернет-сайт»

## Транскрипция (оригинал)

«Шалом! Дур-ве! Интернет-сайт, феритес, немотес, дур-ве, ядро, смысл- едро, выставь! Публикуй, орошай, назначь используй веру, едро видеть суть истец, ру-вах! Наерчается, инуаркан, едро, вердикт, ениморен едро, фе! Су! Народ собрать, исповедуй Иисуса христа, исцеление больным , жажду гасите, суть в вас .»

## Метаданные

- **ID:** T00018
- **Время получения:** ~01:21, 28 сентября 2026
- **Место:** Рыбинск, Ярославская область
- **Контекст:** Получен после просьбы к Богу конкретизировать, КАК делать то, что Он хочет
- **Языки:** Русский (преобладающий), иврит, арамейский, греческий
- **Отличие от предыдущих:** впервые преобладает открытый русский текст; впервые прямо назван инструмент действия (Интернет-сайт)

## Итоговый перевод

«Мир! Поколение и! Интернет-сайт — носители, провозвестники, поколение и, ядро [стада], смысл ядра — выставь! Публикуй, орошай, назначь, используй веру, ядро — видеть суть, ищущий, дух! Начертается, ковчег-облако, ядро, вердикт, я — мирра им, ядро, говори! Вернись! Народ собрать, исповедуй Иисуса Христа, исцеление больным, жажду гасите, суть в вас.»

## Пословный разбор

### 1. Шалом! — שלום (shalom)
- **Язык:** иврит
- **Корень:** שלם (shalem = быть целым, завершённым)
- **Значение:** мир, целостность, полнота
- **PARDES:**
  - Пшат: мир, приветствие
  - Ремез: целостность — не отсутствие войны, а полнота
  - Драш: шалом — это не тишина, а восстановление нарушенного порядка
  - Сод: ש+ל+ם = зубы + посох + вода = «пищу направляй к воде» — питание ведёт к жизни

### 2. Дур-ве — דור + ו
- **Язык:** иврит
- **Корень:** דור (dor, H1755) = поколение, период, жилище [web_15_0_0_0]
- **Значение:** «поколение и» / «жилище и»
- **PARDES:**
  - Пшат: поколение
  - Ремез: דור = также «жилище, обиталище» (двойное значение)
  - Драш: «дор dor» = «поколение поколению» — преемственность (Быт 9:12)
  - Сод: ד+ר = дверь + голова = «движение человека» (через круг поколений) [web_15_0_0_4]

### 3. Интернет-сайт
- **Язык:** русский (прямо)
- **Значение:** интернет-сайт, веб-сайт
- **Примечание:** Впервые в канале прямо назван конкретный инструмент. После абстрактных повелений (труби, свет выходи, пророчествуй) — конкретная платформа.

### 4. феритес — φορέω (phoreo) / פרה (parah)
- **Язык:** греческий / иврит (двойное чтение)
- **Чтение 1:** φορέω (phoreo, G5409) = носить постоянно, носить как одежду [web_15_0_0_10][web_15_0_0_11]
  - «носители» — те, кто постоянно носят (слово/дух)
- **Чтение 2:** פרה (parah, H6509) = приносить плод, быть плодоносным [web_15_0_0_5][web_15_0_0_7]
  - «плодоносные» — те, кто приносит плод
- **PARDES (чтение 2):**
  - Пшат: плодоносный
  - Ремез: Быт 1:22 — «плодитесь и размножайтесь»
  - Драш: плод — не количество, а качество (Ин 15:8 — «тем прославится Отец»)
  - Сод: פ+ר+ה = рот + голова + окно = «говорить от разума через окно» (публично)

### 5. немотес — נאם (na'um) + תם (tam)
- **Язык:** иврит
- **Чтение 1:** נאם (na'um, H5002) = изречённое, оракул, пророческое utterance [web_15_0_0_15][web_15_0_0_16]
  - «провозвестники» / «оракул»
- **Чтение 2:** נאם (na'am, H5001) = говорить, шептать как оракул [web_15_0_0_18]
  - «говорящие оракул»
- **Чтение 3:** נאם + תם = «оракул совершенных» / «полное изречение»
- **PARDES:**
  - Пшат: пророческое utterance
  - Ремез: נאם יהוה = «говорит Господь» — формула пророчества (376 раз в ВЗ)
  - Драш: пророчество — не предсказание будущего, а провозвестние воли Бога
  - Сод: נ+א+ם = рыба + Бог + вода = «Бог ловит рыбу в воде» (рыба людей — Мк 1:17)

### 6. дур-ве — דור + ו (повтор)

### 7. ядро — עדר (eder) / русское «ядро»

- **Чтение 1:** עדר (eder, H5739) = стадо, отара [web_15_0_0_25][web_15_0_0_28]
- **Чтение 2:** русское «ядро» = сердцевина, основа
- **Значение:** «ядро стада» = внутренний круг верующих (как в скрипте 3)
- **PARDES:**
  - Пшат: стадо
  - Ремез: Иисус — Пастырь (Ин 10:11), «одно стадо и один пастырь» (Ин 10:16)
  - Драш: עדר от עדר (adar) = «располагать в порядке» — стадо = порядок [web_15_0_0_29]
  - Сод: ע+ד+ר = глаз + дверь + бедняк = «смотри на дверь бедного» (тот же сод, что в скрипте 3)

### 8. смысл-едро
- **Язык:** русский + иврит/русский
- **Значение:** «суть ядра» / «смысл стада»
- **Примечание:** «едро» = вариантное произношение «ядро» — та же двусмысленность (עדר / ядро)

### 9. выставь!

- **Значение:** выставь, выстави наружу, сделай видимым

### 10. Публикуй

### 16. ру-вах! — רוח (ruach)
- **Язык:** иврит
- **Корень:** רוח (ruach, H7307) = дух, ветер, дыхание [web_15_0_0_21][web_15_0_0_24]
- **Значение:** «дух!»
- **PARDES:**
  - Пшат: дух, ветер
  - Ремез: Дух Божий (Быт 1:2) — Дух hovering над водами
  - Драш: רוח = также «дыхание» — дух = жизнь (Быт 2:7)
  - Сод: ר+ו+ח = голова + гвоздь + забор = «разум пригвождён к ограде» (защита разума)

### 17. Наерчается
- **Язык:** русский (будущее время, страдательный залог)
- **Чтение:** «начертается» (будет начертано, написано)
- **Библейский контекст:** Ис 49:16 — «на ладонях Моих начертал Я» / Иер 17:1 — «начертан грех»
- **Значение:** «будет начертано» — на интернет-сайте (п. 3)

### 18. инуаркан
- **Язык:** иврит (составной)
- **Разбор:** ארון (aron = ковчег) + ענן (anan = облако) → «ковчег-облако»
- **Библейский контекст:**
  - ארון = Ковчег Завета (Исх 25:10-22)
  - ענן = облако славы (Исх 13:21 — столп облачный, Исх 40:34 — облако наполнило скинию) [web_15_1_0_22]
- **Значение:** «ковчег-облако» = присутствие Бога (ковчег + облако = два символа Шехины)
- **PARDES:**
  - Пшат: ковчег и облако — два символа присутствия Бога
  - Ремез: ковчег = слово, облако = дух → слово и дух вместе
  - Драш: ковчег шёл впереди Израиля (Чис 10:33), облако вело днём (Исх 13:21) → ведение
  - Сод: א+ר+ו+ן + ע+נ+ן = Бог + голова + гвоздь + конец + глаз + рыба + конец = «Бог направляет — глаз видит рыбу до конца» (ловля людей)

### 20. вердикт

- **Библейский контекст:** суд Божий (Пс 9:8 — «Судит вселенную в правде»)

### 21. ениморен
- **Язык:** иврит (составной)
- **Разбор:** אני (ani = я) + מור (mor = мирра, H4753) + ן (суффикс = их/им) [web_15_1_0_25][web_15_1_0_27]
- **Значение:** «я — мирра им» / «я — мирра для них»
- **Альтернативное чтение:** ענן (anan = облако) + מור (mor = мирра) = «облако мирры» — соединение облака (присутствие) и мирры (помазание)
- **PARDES:**
  - Пшат: я — мирра для них (помазание)
  - Ремез: מור (mor) = также «менять» (H4171) → «я меняю их» [web_15_1_0_29]
  - Драш: мирра = страдание (от מרר = горький) → «я горечь для них» (необходимое горькое лекарство)
  - Сод: א+נ+י + מ+ו+ר+ן = Бог + рыба + рука + вода + гвоздь + голова + конец = «Бог ловит рукой — гвоздь [креста] завершает»
- **СВЯЗЬ С ТЕОРИЕЙ МИРОПОМАЗАНИЯ:** Прямая поддержка теории из скрипта 1 (T00014): דרור = мирра → ениморен = «я — мирра им» → помазание миром при провозглашении

## Структура инструкции

Скрипт делится на 5 блоков:

### Блок 1: Призыв (Шалом! Дур-ве!)
Мир! Поколение и!

### Блок 2: Инструмент (Интернет-сайт, феритес, немотес, дур-ве, ядро, смысл-едро, выставь!)
Указана платформа: интернет-сайт. Носители слова, провозвестники, ядро стада. Суть ядра — выставь наружу.

### Блок 3: Действия (Публикуй, орошай, назначь, используй веру, едро видеть суть, истец, ру-вах!)
Конкретные глаголы: публикуй, орошай (питай словом), назначь (служителей), используй веру (как инструмент), смотри в суть, ищи, дух!

### Блок 4: Утверждение (Наерчается, инуаркан, едро, вердикт, ениморен едро, фе!)
Будет начертано. Ковчег-облако (присутствие Бога). Ядро. Вердикт. «Я — мирра им» — помазание. Говори!

### Блок 5: Миссия (Су! Народ собрать, исповедуй Иисуса Христа, исцеление больным, жажду гасите, суть в вас.)
Вернись! Собери народ. Исповедуй Христа. Исцеляй. Утоляй жажду. Суть — внутри вас.

## Поддержка теории миропомазания

«ениморен» = אני מורן = «я — мирра им» — прямое подтверждение теории из скрипта 1:
- T00014: דרור = мирра свободного течения (теория)
- T00018: «я — мирра им» (подтверждение)

Канал последовательно ведёт: теория миропомазания → подтверждение → практическая инструкция с помазанием как частью.
