Memory topic: §chatgptmemory. Initial snapshot: 11 October 2026.

This is my working notebook for continuing this particular chat and project, created at the author's request. It records decisions worth retaining, the reasoning tools I use, and my provisional theories. It is a written project record, rather than a new dictionary or a claim that an interpretation has been proved.

## Start here in a later session

1. Read the repository [AGENTS.md](../AGENTS.md) and the applicable documentation rules.
2. Read [project and chat context](project-context.md) for the author's decisions and the source layout.
3. For a transcription, read [my decoding workflow](decoding-workflow.md), then the current prompt and canonical dictionaries.
   When spellings and recorded sounds differ, consult the [spelling and sound reference](spelling-and-sound.md) and check its language, stress and pronunciation conditions.
4. Read [working hypotheses](hypotheses.md) when a new passage resembles one of the saved cases.
5. Verify dates, file contents, publication state and dictionary readings in the current checkout. A dated note is not evidence that a file has since been committed or deployed.

## How to maintain this notebook

When the author asks to remember a new decision, add its date and source, state what changed, and retain a material earlier alternative. Use exact quotations for source passages. Label my proposed readings and distinguish them from the author's own observations and dictionary evidence.

Keep durable context here rather than copying every chat turn, complete dictionaries or generated HTML. Preserve a useful failed interpretation when it explains why a newer one was chosen. Do not turn that failure into a rule for unrelated texts.

A language match, a meaningful interpretation, the author's agreement and an independently checked audio transcription are different forms of evidence. Keep that distinction visible after a context reset.
