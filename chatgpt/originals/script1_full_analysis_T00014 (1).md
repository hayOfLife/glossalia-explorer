## Необработанная транскрипция

> Херувиме-н! савед, ре-! Ишма-де, ру, си-фа де-ру... Неволеваетерентесодевитене-д! Ишма дерво-ли — Суда вы едро — выед ро ве ли-не — Холаспис, етерогреаль, Ситоргентум (фирастлифениядонте). Ишма-де ворутение, кщение-девостени.

---

## Назначение скрипта

**Скрипт для христианина, у которого завет с Богом уже есть.** Канал глоссолалии открывается не с нуля, а через существующий завет — как ток по уже проложенному проводу.

Три элемента подтверждают, что человек уже верующий:

1. **שבע (савед) = «обет»** — обет уже есть. Скрипт не устанавливает обет, а обращается к существующему: «обет — видь его!»
2. **ברית (ворутение) = «завет»** — завет уже есть. Скрипт говорит «дай [действовать] завету» — активируй то, что заключено
3. **קדש (кщение) = «освяти!»** — освящение возможно только того, что уже принадлежит Богу. Нельзя освятить то, что не Его

**Вывод:** скрипт = ритуал инициализации канала глоссолалии через существующий завет христианина. Не создание завета — активация через завет.

## Полный разбор элементов

### 1. Херувиме-н!
**כרובים (керувим)** — херувимы
- Стражи входа: поставлены у входа в Эдем с пламенным мечом (Быт 3:24)
- Изображения на крышке Ковчега — место присутствия Бога (Исх 25:18-22)
- **Скрипт начинается с призыва к стражам канала**
- Суффикс -н: возможно ן (конец) или -ם (множественность)

### 2. савед
**שבע (шава)** — «обет, клятва» (H7650)
- Не «знающий» (как в предыдущем разборе), а **обет**
- Шава = давать обет, клясться (Быт 21:31, 31:53)
- Основание канала через клятву/обет
- **Исправление:** было «знающий» → стало «обет»

### 3. ре
**ראה (ра)** — «видь!» (H7200)
- Повелительное наклонение: «видь! смотри!»
- Обращение к обету: «обет — видь!»

### 4. Ишма-де
**שמע (шма) + די (ди)** — «услышь это!»
- שמע = слышать (H8085) — как «Шма, Исраэль»
- די = «это, достаточно»
- «Услышь это!» — обращение к носителю

### 5. ру
**רוח (руах)** — «дух» (H7307)
- Дух = основа канала
- רוח = дух, ветер, дыхание
- Канал глоссолалии = дух, проходящий через уста

### 6. си-фа
**שפה (сафа)** — «язык, речь» (H8193)
- Скала (сфа) = губа, язык, речь
- «Язык духа» = канал определён: дух → язык

### 7. де-ру
**די + רוח** — «этого духа»
- Или: דרור (дерор) — «свободное течение» (H1865)
- Мирра свободного течения (Исх 30:23) — как образ духа, текущего свободно

### 8. Неволеваетерентесодевитене-д (ДЛИННАЯ СТРОКА — «КЛЮЧ»)

**Сегментация:**
נבוא לב ἕτερος סוד בית תן (наво лев этеросод бейт тэн)

| Сегмент | Корень | Значение |
|---------|--------|----------|
| нево | נבוא (наво) | «пророчествуй!» (H5012) |
| ле | לב (лев) | «сердце» (H3820) |
| ва/ете | ἕτερος (этерос) | «иной, другой» (G2087) |
| рент | סוד (сод)? | «тайна» (H5475) |
| есод | סוד (сод) | «тайна» — или בסוד = «в тайне» |
| евитене | בית תן (бейт тэн) | «дом — дай!» |
| -д | ד (далет) | возможно начало след. элемента |

**Перевод:** «Пророчествуй! Сердце — иная [речь] — тайна — дом — дай»

**Три прямые ссылки на 1 Кор 14:**
- נבוא (пророчествуй) → 1 Кор 14:1: «ревнуйте... пророчествовать»
- ἕτερος (иной) → 1 Кор 14:21: «иными языками буду говорить»
- סוד (тайна) → 1 Кор 14:2: «говорит тайны (μυστήρια)»

### 9. Ишма
**שמע (шма)** — «услышь!» (H8085)
- Повторное обращение: «услышь!»

### 10. дерво-ли
**דרור + לי (дерор ли)** — «свободу мне!»
- דרור = свобода, свободное течение (H1865)
- Мирра свободного течения (Исх 30:23) — дух, текущий без препятствий
- לי = «мне»
- **Исправление:** было «основание ли?» → стало «свободу мне!»
- «Свободу мне!» = разблокировка потока канала

### 11. Суда
**סוד (сод)** — «тайна, совет» (H5475)
- Не «суд» (как в предыдущем разборе), а **тайна**
- Прямая ссылка на 1 Кор 14:2: «говорящий языком... говорит тайны»
- **Исправление:** было «суд» → стало «тайна»

### 12. вы
**בו (во)** — «в нём» (H906)
- Или: בי (би) — «во мне»
- «Тайна — в нём» или «тайна — во мне»

### 13. едро
**עדר (эдер)** — «стадо, пасти» (H5739) / **φέρω (феро)** — «нести» (G5342)
- Если עדר: канал = стадо, которое пасут
- Если φέρω: канал = то, что несёт носитель
- **Оба корня присутствуют в системе** — עדр в скрипте защиты канала, φέρω в скрипте для Алексея
- Возможно двойное чтение: «паси» и «неси» одновременно

### 14. выед ро ве ли-не
**בית + עדר + רוח + בל + לי + ני**
| Сегмент | Корень | Значение |
|---------|--------|----------|
| выед | בית עדר (бейт эдер) | «дом стада» |
| ро | רוח (руах) | «дух» |
| ве | בל (баль) | «нет, не» |
| ли | לי | «мне» |
| не | ני (ни) | «меня» (суффикс) |

**Перевод:** «Дом стада — дух — не мне [только] — меня»
- Или: «Дом стада духа — не мне, [но] мне» — парадокс: канал не для себя, но через себя

### 15. Холаспис
**ὅλος + ἀσπίς (холос + аспис)** — «полный щит»
- ὅλος = целый, полный (G3650)
- ἀσπίς = щит (G804)
- «Полный щит» = защита канала, цельная, без пробоин
- Образ: щит, покрывающий весь канал

### 16. етерогреаль
**ἕτερος + γρᾰφω (этерос + графо)** — «иное писание»
- ἕτερος = иной, другой рода (G2087) — из 1 Кор 14:21
- γρᾰφω = писать, записывать (G1125)
- «Иное писание» = **транскрипция**!
- **Исправление:** было «иная речь или путь» → стало «иное писание» = транскрипция
- Канал глоссолалии → транскрипция: иная речь записывается

### 17. Ситоргентум
**סיט (сит)? + λαός (лаос)? + ...**
- Возможно: λαός (лаос, G2992) = народ → «для народа»
- Или: סתר (сетер) = скрытое + λαός = «скрытое для народа»
- Или: κένtrum (центр) = средоточие
- **Предположительно:** «для народа» — назначение канала: не для себя, для народа

### 18. фирастлифениядонте (в скобках)
**Возможная сегментация:**
| Сегмент | Корень | Значение |
|---------|--------|----------|
| фи/ра | פרה (пара) | «плодоноси!» (H6500) |
| ст/лиф | שת (шат) | «основание» (H8356) |
| ени | ענה (ана) | «отвечай!» (H6030) |
| я/дон | δόωμι (дотоми) | «даруй» (G1325) |
| те | תן (тэн) | «дай!» (H5414) |

**Перевод:** «Плодоноси — основание — отвечай — даруй — дай!»
- Скобки = пояснение к «для народа»: что должно произойти для народа
- «Плодоноси» — канал должен приносить плод
- «Отвечай» — канал отвечает на запрос
- «Даруй/дай» — двойное усиление: дай!

### 19. Ишма-де
**שמע + די** — «услышь это!» (повтор)
- Третье «услышь» в скрипте — обращение к носителю снова

### 20. ворутение
**ברית + תנה (брит + тна)** — «дай завет!»
- ברית = завет (H1285) — рассечённый союз (от ברת = рассекать)
- תנה = дай (H8418)
- «Дай завет!» = приведи в действие существующий завет
- **Исправление:** было «пребывание в духе» → стало «дай завет!»

### 21. кщение
**קדש (кадеш)** — «освяти!» (H6942)
- קדש = отделить для Бога, освятить
- «Освяти!» — отделение канала и носителя для Бога
- **Исправление:** было «возжигание» → стало «освяти!»

### 22. девостени
**סתר + ני (сетер ни)** — «укрой меня!»
- סתר = скрывать, укрывать (H5641)
- ני = меня (суффикс 1-го лица)
- «Укрой меня!» — финал: защита носителя после активации канала
- **Исправление:** было «в этих стенах» → стало «укрой меня!»
